# p2p-network 고지문이 자기 구현과 모순된다

Status: resolved
Section: P2
Tags: 정정

페이지 최상단 `IllustrativeDisclaimer`:

```text
전파 그래프는 실제 무작위 P2P 그래프 대신 격자로,
동기화 속도는 실제 네트워크 대역폭 대신 일정한 라운드 단위로 근사했다.
```

그런데 `lib/p2p-concept.ts`:

```text
그래프가 격자가 아니라 무작위라는 점(그래서 홉 수가 적다는 스몰월드 성질)은
실제와 같은 구조로 재현한다.
```

`generateGossipGraph`는 무작위 스패닝 트리에 무작위 간선을 더한 무작위 그래프를 만든다. 탭 안의 배너도 "격자보다 훨씬 적은 홉 수로 퍼지는 걸"이라며 격자와 대비한다.

페이지 배너가 옛 구현을 설명한 채 남았고, 독자가 가장 먼저 보는 문장이 시뮬레이션을 실제보다 부실하게 소개하고 있다.

## 할 일

- 페이지 배너에서 격자 서술을 걷어낸다
- 페이지 배너와 탭 배너의 역할을 나눈다. 페이지 배너는 세 탭 전체에 걸친 단순화만, 탭 배너는 그 탭 고유의 생략만

## Answer

페이지 배너에서 격자 서술을 걷어내고 두 배너의 역할을 나눴다.

```text
페이지 배너   세 탭 전체에 걸친 단순화만
              "세 시뮬레이션 모두 시간을 라운드 단위로 끊어 보여준다. 실제로는 전파도
               동기화도 네트워크 대역폭과 지연에 따라 연속으로 일어난다.
               각 탭이 무엇을 더 줄였는지는 탭 안에서 따로 밝힌다."
탭 배너       그 탭 고유의 생략만 (노드 40개·평균 연결 5개로 줄인 것)
```

화면에서 두 배너가 맞붙어 있어 모순이 특히 두드러졌다. 이제 페이지 배너가 탭 배너를 가리키므로 이중 게시가 아니라 층위가 된다.
