# 키 트리에서 HMAC 출력이 화면에 없어 "시드를 쪼갠다"로 읽힌다

Status: resolved
Section: P1
Tags: 직관성, 일관성

`key-tree` 탭의 마스터 단계가 이렇게 그려져 있었다.

```text
시드 (512비트)
  ↓ HMAC-SHA512 (key = "Bitcoin seed") → 64바이트를 둘로 분할
마스터 개인키 (왼쪽 32B)    마스터 체인코드 (오른쪽 32B)
```

시드도 64바이트고 HMAC 출력도 64바이트다. 중간값이 화면에 없으니 시드 자신이 반으로 쪼개지는 것처럼 읽힌다. 실제로는 시드가 HMAC의 입력이고, 쪼개지는 건 그 출력이다.

같은 페이지 ① 탭은 엔트로피 → 해시 결과(256비트) → 앞 4비트 잘라냄 → 체크섬으로 중간값을 다 보여준다. 한 페이지 안에서 방식이 갈렸다.

## Answer

HMAC 출력 I를 중간 상자로 노출하고 연산 라벨을 둘로 나눴다.

```text
시드 (512비트) · HMAC의 입력
  ↓ HMAC-SHA512 (key = "Bitcoin seed")
HMAC 출력 I (64바이트)
  ↓ 이 출력을 앞뒤 32바이트씩 둘로 나눈다 (쪼개지는 건 시드가 아니라 이 값이다)
마스터 개인키 (왼쪽 32B)    마스터 체인코드 (오른쪽 32B)
```

화면 값을 검사해 HMAC 출력이 개인키+체인코드의 연결과 정확히 일치하고 시드와는 다름을 확인했다.
