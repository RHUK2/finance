# 결제 채널의 온체인 지표가 죽어 있고 상태와 모순된다

Status: resolved
Section: P3
Tags: 정정, 직관성

```text
오프체인 업데이트  0회
온체인 트랜잭션    2건 (열기·닫기)   ← 하드코딩 상수
채널 상태          열림
```

채널이 열려 있는 동안 온체인 트랜잭션은 열기 1건뿐인데 2건이라 표시된다. 바로 옆 `채널 상태: 열림`과 어긋나고, 채널을 닫아도 값이 변하지 않아 지표가 죽어 있다.

같은 카드의 배너도 "온체인에는 아직 아무 기록도 없다"고 했는데, 채널을 연 트랜잭션은 이미 온체인에 있다.

## Answer

지표를 상태에 연동했다. `열림 → 1건 (열기. 닫을 때 한 건 더)`, `닫힘 → 2건 (열기 · 닫기)`. 이제 채널을 닫으면 지표가 1에서 2로 움직여, 오프체인을 몇 번 하든 온체인 발자국은 둘뿐이라는 이 페이지의 논지가 지표에서 직접 보인다.

배너 문구도 "채널을 연 트랜잭션 하나 말고는 온체인에 아무 기록도 남지 않았다"로 고쳤다.
