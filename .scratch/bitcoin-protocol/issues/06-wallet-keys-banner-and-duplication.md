# 지갑 키 생성 배너가 자기 정확성을 부정하고, 공용 프리미티브를 복제했다

Status: resolved
Section: P1
Tags: 정정, 일관성, 중복

배너가 "여기서 만들어지는 단어·시드·주소는 그럴듯한 가짜 값이다"라고 말한다. 확인해 보니 단어는 진짜다.

```text
단어장     2048개, abandon(0) ~ zoo(2047), 실제 BIP-39 목록
매핑       엔트로피 → 11비트 청크 → 인덱스 → 단어, 화면의 12개 전부 대조 통과
가짜인 것  체크섬(과 그 영향을 받는 마지막 단어) · 시드 · 주소
```

같은 그룹의 `script-verify`는 같은 자리에서 "스크립트 실행 순서와 스택 규칙(②)만 실제와 같다"고 무엇이 진짜인지 밝힌다. `wallet-keys`만 자기 강점을 지운다.

게다가 이 배너는 공용 `IllustrativeDisclaimer`를 로컬로 복제한 것이었다. `Card` 클래스·`TriangleAlert`·"교육용 개념 시연" 문구까지 마크업이 동일하다. `CLAUDE.md`가 "새 시뮬레이션 페이지는 로컬 복제 대신 여기서 import"라고 명시한 대상이다.

## Answer

로컬 복제를 지우고 `IllustrativeDisclaimer`를 쓴다. 문구도 "반면 단어장 2048개와 엔트로피를 11비트씩 잘라 단어로 바꾸는 규칙(①)은 실제 BIP-39 그대로다"를 덧붙여 무엇이 진짜인지 밝힌다.
