# 대시보드에 h1을 붙이지 않기로 한다

Status: wontfix
Section: S4
Tags: 일관성

S0에서 `/bitcoin`과 `/mempool`만 h1·인트로·`max-w-5xl`이 없어 인사이트 그룹에서 튄다고 기록했다. 그래서 S4의 과제를 "껍데기 일관성 맞추기"로 잡았다.

## Answer

전제가 틀렸다. 인사이트 그룹만 보지 말고 사이트 전체를 봤어야 했다.

```text
데이터 대시보드 5개   h1 없음 · 전폭 · 합니다체
  자산 현황 · 경제 차트 · 원자재 차트 · 비트코인 차트 · 비트코인 네트워크

설명형 페이지         h1 · max-w-5xl · 해라체
  인사이트 7개 · 프로토콜 10개 · 화폐 · 기업 · 부동산
```

`/bitcoin`과 `/mempool`은 이미 자기 부류와 일관적이다. h1을 붙이면 오히려 `/economy`·`/commodities`와 어긋난다. `/bitcoin`의 `전체 스케일 초기화` 버튼도 두 형제 페이지와 구현이 같다.

문체도 같은 결론이다. `/mempool`의 합니다체는 인사이트 그룹 안에서는 혼자지만 대시보드 부류 안에서는 표준이다. 데이터를 보여 주는 화면은 존대, 개념을 설명하는 화면은 평서라는 구분이 사이트 전체에 이미 서 있다.

껍데기는 손대지 않는다. 대신 이 두 갈래 규약을 `spec.md`에 기록했다.
