# 자연의 파워 프로젝션 격자를 나머지 두 캐스케이드와 같은 수준으로 맞춘다

Status: resolved
Section: S1
Tags: 직관성, 일관성

`softwar/primordial-economics`는 `AgentGrid`·`RoundControls`·`Sparkline`을 다른 두 시뮬레이션과 똑같이 쓰면서도 완성도만 낮았다.

- 개체를 정렬하지 않아 초록·주황·파랑이 무작위로 흩어졌고 구조가 전혀 읽히지 않았다
- 축 라벨(낮음 ↔ 높음)이 없었다
- 격자 읽는 법 설명문이 없었다
- 궤적을 미리 계산하지 않아 `생존 곡선`이 라운드 0에서 라벨만 있고 비어 있었다
- `total`을 넘기지 않아 라운드 스크러버가 없고 `라운드 0`으로만 표시됐다(다른 둘은 `라운드 0 / 9`)

## Answer

`buildOrganisms`가 투사력 오름차순으로 정렬해 돌려주도록 했다. 포식 압력이 아래에서 위로 차오르므로 도태 집합이 앞에서부터의 연속 구간이 되고, 도태 경계가 왼쪽에서 오른쪽으로 전진하는 선으로 보인다. ADR-0001이 채택 캐스케이드·홀더 딜레마에 세운 원칙과 같다.

`predationTrajectory`를 추가해 궤적을 미리 계산한다. 압력이 라운드마다 정해진 폭으로 차오르는 결정론적 모델이라 가능하다. 덕분에 스크러버와 곡선 미리보기가 붙었다.

나머지는 `CascadeStage`(티켓 04)로 들어가면서 함께 채워졌다.
