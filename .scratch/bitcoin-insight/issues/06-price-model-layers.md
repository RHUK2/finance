# 세 가지 가격 모델이 서로를 언급하지 않는다

Status: resolved
Section: S2
Tags: 정정

이 사이트는 비트코인 가격에 세 모델을 쓴다.

| 위치                               | 모델                         | 답하는 질문                  |
| ---------------------------------- | ---------------------------- | ---------------------------- |
| `bitcoin/rainbow-chart`            | Power Law 공정가치           | 장기 추세 대비 지금 어디인가 |
| `bitcoin-volatility/two-regime`    | 성공 확률 p × 터미널 가격    | 왜 이렇게 출렁이는가         |
| `bitcoin-game-theory/hodl-dilemma` | 매도 압력에 따른 반사적 하락 | 폭락은 어떻게 증폭되는가     |

층위가 다르므로 중복이 아니다. 다만 어느 페이지도 자기 모델이 무엇에 답하는 모델인지 밝히지 않아, 여러 페이지를 읽은 독자에게는 서로 모순돼 보인다.

## 할 일

- `two-regime`과 `hodl-dilemma`의 설명에 각 모델이 답하는 질문의 범위를 한 문장으로 넣는다
- Power Law는 `/bitcoin` 차트 페이지 소관이며 S4는 껍데기만 손대므로 이번에는 건드리지 않는다

## Answer

변동성 페이지 인트로에 "여기서 쓰는 가격 모델은 '왜 출렁이는가'에 답하는 것이지 적정 가격을 계산하는 모델이 아니다"를 넣었고, 홀더 딜레마 인트로에 "이 모델은 폭락이 어떻게 증폭되는지를 설명할 뿐 비트코인의 가치가 얼마인지는 말하지 않는다"를 넣었다. Power Law는 예정대로 건드리지 않았다.
