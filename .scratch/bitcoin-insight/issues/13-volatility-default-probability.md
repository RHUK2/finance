# 변동성 페이지의 두 탭이 같은 모델에 다른 확률을 쓴다

Status: resolved
Section: S2
Tags: 정정

```text
두 갈래 운명     기본 p=15%  →  함의 가격 $235.7K
변동성의 정체    START_P=5%  →  현재 가격  $78.6K
실제 시세                        $74,778
```

앞 탭은 실제 시세의 3배를 내놓고 뒤 탭만 현실과 맞았다. 같은 페이지 안에서 같은 모델이 다른 답을 내는 셈이다.

`GOLD_CAP`도 어긋나 있었다. 주석은 온스당 $4,800 기준이라 밝히는데 실제 금값은 $4,549였다.

## Answer

`GOLD_CAP`을 $31.6조로 갱신하고 기준 시점을 2026년 8월로 명시했다. 두 갈래 운명의 기본 p를 5%로 내려 두 탭이 같은 값에서 출발한다.

여기에 `impliedProbability`를 추가해 실제 시세가 함의하는 확률을 라이브로 보여 준다. 이 페이지는 성숙 곡선 탭에서 이미 라이브 데이터를 쓰므로 새 패턴이 아니다. 다만 성숙 곡선이 쓰는 `bitcoin-historical`은 일간 종가라 하루 늦고 자산 현황 페이지가 보여 주는 값과 어긋나므로, 여기서는 `useMarket`의 실시간 시세를 쓴다.

지금 시세 $75.2K가 성공 확률 4.9%를 함의하고 기본값 5%와 맞아떨어진다.
