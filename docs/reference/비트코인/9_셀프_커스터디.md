자기 수탁(Self-Custody)이란 제3자(거래소, 은행)에게 비트코인을 맡기지 않고 개인 키를 직접 관리하는 것을 말한다. "Not Your Keys, Not Your Coins" 의 원칙을 실천하는 방법이다.

---

## 지갑의 종류

### 하드웨어 지갑 (콜드 월렛, Cold Wallet)

개인 키를 인터넷과 완전히 분리된 전용 장치에 보관하는 방식. Coldcard, Ledger, Trezor 등이 대표적이며, 서명 과정도 오프라인에서 수행하므로 해킹 공격 면에서 가장 안전하다.

### 소프트웨어 지갑 (핫 월렛, Hot Wallet)

인터넷에 연결된 기기(스마트폰, PC)에서 실행되는 지갑 앱. 편의성이 높지만 악성코드나 해킹에 노출될 위험이 있어 소액 일상 결제 용도에 적합하다.

## 핵심 보안 요소

### 시드 구문 (Seed Phrase / BIP39)

HD(계층 결정적) 지갑에서 모든 개인 키를 파생시키는 근원이 되는 12~24개의 영어 단어 목록. 이 단어들만 있으면 어떤 기기에서든 지갑을 완전히 복구할 수 있으므로, 절대로 디지털 기기에 저장하거나 온라인에 노출해서는 안 된다.

### 패스프레이즈 (Passphrase / 25번째 단어)

시드 구문에 추가하는 사용자 지정 비밀번호로, 동일한 시드에서 완전히 다른 지갑 주소 집합을 파생시킨다. 시드 구문이 물리적으로 탈취되더라도 패스프레이즈를 모르면 접근이 불가능하므로 보안 계층을 한 단계 추가한다.

### 에어갭 서명 (Air-Gap Signing)

서명 장치가 어떠한 유선 또는 무선 연결도 없이 QR코드, SD카드, NFC 등을 통해서만 외부와 데이터를 주고받는 방식. 물리적으로 인터넷 연결이 차단되어 원격 공격이 원천적으로 불가능하다.

### 상속 계획 (Inheritance Planning)

키 보유자가 사망하거나 의식을 잃었을 때 신뢰할 수 있는 상속인이 비트코인에 접근할 수 있도록 미리 절차를 설계하는 것. 다중 서명 구조, 시간 잠금(Timelock), 또는 신뢰할 수 있는 제3자에게 일부 키를 위탁하는 방식 등이 활용된다. 설계 없이 사망하면 비트코인은 영구 소실된다.

## 비트코인 프라이버시

비트코인 블록체인은 모든 트랜잭션이 공개적으로 기록되므로 완전한 익명성을 제공하지 않는다. 주소와 신원이 연결되면 전체 거래 이력이 추적 가능하다. 따라서 프라이버시는 프로토콜 수준이 아닌 사용자의 행동 수준에서 관리해야 한다.

### CoinJoin

서로 관계없는 여러 사용자의 트랜잭션을 하나의 트랜잭션으로 합쳐 어떤 입력이 어떤 출력으로 연결되는지 추적하기 어렵게 만드는 기법. 중앙 조정자 없이도 구현 가능하며 Wasabi Wallet, JoinMarket 등이 활용한다.

### 주소 재사용 금지

동일한 비트코인 주소를 여러 번 사용하면 해당 주소로 들어오고 나가는 모든 트랜잭션이 연결되어 잔액과 거래 패턴이 노출된다. HD 지갑은 매 거래마다 새 주소를 자동 생성하여 이 문제를 완화한다.

### UTXO 관리 (코인 컨트롤, Coin Control)

트랜잭션 생성 시 어떤 UTXO를 입력으로 사용할지 수동으로 선택하는 기능. 출처가 다른 UTXO를 하나의 트랜잭션에 함께 사용하면 공통 입력 소유권(Common Input Ownership) 추론으로 신원이 연결될 수 있으므로, 출처별로 UTXO를 분리 관리하는 것이 중요하다.

### Tor / VPN과 노드 운영

비트코인 트랜잭션을 브로드캐스트하거나 노드를 운영할 때 IP 주소가 노출되면 신원이 추적될 수 있다. Tor 네트워크나 VPN을 통해 IP를 숨기면 트랜잭션 발신자와 실제 IP 주소의 연결을 차단할 수 있다.

### 체인 분석 (Chain Analysis)

블록체인 데이터를 통계적·휴리스틱적으로 분석하여 주소 군집화, 거래 패턴 추적, 신원 연결을 시도하는 기법. Chainalysis, Elliptic 등의 기업이 상업적으로 서비스를 제공하며 거래소의 AML(자금세탁방지) 준수에 활용된다.
