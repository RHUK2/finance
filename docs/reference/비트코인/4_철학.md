## 핵심 원칙

- Don't Trust, Verify (신뢰하지 말고 검증하라): 중앙 기관의 말을 믿는 대신, 누구나 직접 노드를 운영하여 네트워크의 규칙이 지켜지고 있는지 스스로 검증할 수 있다는 원칙
- Not Your Keys, Not Your Coins (키가 없다면 당신의 비트코인이 아니다): 거래소나 제3자에게 비트코인을 맡기는 것은 엄밀히 말해 비트코인을 소유한 것이 아님. 오직 개인 키(Private Key)를 직접 소유하고 관리할 때만 진정한 소유권이 발생함

## 비트코인 = 복원

비트코인은 혁명이 아니라 국가가 제거한 "발행 제한"을 수학으로 복원한 것이다.

| 항목      | 달러 (1971년 이후) | 비트코인        |
| --------- | ------------------ | --------------- |
| 발행 주체 | 국가 (중앙은행)    | 없음 (코드)     |
| 발행량    | 무제한             | 2,100만 개 고정 |
| 담보      | 없음 (신뢰)        | 없음 (수학)     |
| 철학      | "우리를 믿어라"    | "검증하라"      |

현재 시스템에서는 잘못된 결정을 해도 국가가 구제해준다(Too Big to Fail). 비트코인에서는 코드가 협상하지 않는다. 잘못된 결정 → 본인이 전적으로 부담한다.

## 비트코인이 해결하는 것

| 항목             | 평가                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| 발행 통제권 박탈 | 해결 — 누구도 마음대로 찍어낼 수 없음                                    |
| 검열 저항        | 해결 — 계좌 동결, 거래 차단 불가                                         |
| 중간자 제거      | 해결 — 은행 없이 개인 간 직접 이전                                       |
| 부의 집중        | 난제 — 어느 시스템도 완전 해결 불가. 단, 시스템이 집중을 강제하지는 않음 |
| 이자/부채        | 순수 비트코인 생태계에서는 대출이 순수 개인 간 합의 → 실패는 개인 책임   |
| 변동성           | 장기적으로 네트워크 효과로 감소 추세                                     |
| 자기 보관        | 거래소 파산 손실은 개인 책임 — "Not your keys, not your coins"           |

## 화폐와 국가의 분리

역사적으로 화폐는 국가가 발명한 것이 아니다. 조개껍데기, 유리구슬, 은, 금 등 시장 참여자들이 교환하기 가장 좋은 것을 자연스럽게 화폐로 채택해왔다. 국가는 나중에 그 화폐를 통제하고 권력을 유지하기 위해 독점했을 뿐이다.

지금처럼 아무런 실물 기반 없이 국가가 독단적으로 종이돈을 찍어내는 시기는 1971년 이후 불과 50여 년밖에 되지 않는다.

비트코인은 이 비정상적인 '국가의 통화 독점 시대'를 끝내고, 통화 발행 권력을 부패한 정부에서 수학과 암호학을 기반으로 한 전 세계의 네트워크로 되찾아오는 역사적인 권력 이동이다.
