## Part 1. 게임이론 핵심 개념

### 1. 우월 전략 (Dominant Strategy)

다른 플레이어의 선택과 무관하게 항상 최선인 전략. 상대방이 어떤 선택을 해도 우월 전략의 보상은 다른 전략의 보상보다 크거나 같다.

비트코인 적용 — 채굴자 입장에서 "정직하게 채굴"이 우월 전략이다.

- 51% 공격은 성공을 보장하지 않고, 성공해도 비트코인 가치가 폭락한다.
- 정직하게 참여하면 블록 보상과 수수료를 꾸준히 획득한다.

---

### 2. 내쉬균형 (Nash Equilibrium)

모든 플레이어가 상대방의 전략을 알고 있어도 이탈 유인이 없는 상태. 어떤 플레이어도 혼자 전략을 바꿔서 더 이득을 볼 수 없는 균형점이다.

판별 질문 — "지금 내 전략을 바꾸면 더 나아지는가?"

- YES → 내쉬균형 아님 (이탈 유인 있음)
- NO → 내쉬균형 후보 (모든 플레이어에게 동시에 NO면 확정)

예시 — 연락이 안 되는 두 친구가 A카페 또는 B카페 중 하나를 선택해야 하는 상황. 같은 곳을 골라야 만날 수 있다.

|           | 상대: A카페 | 상대: B카페 |
| --------- | ----------- | ----------- |
| 나: A카페 | 만남 ✓      | 헛걸음      |
| 나: B카페 | 헛걸음      | 만남 ✓      |

- "둘 다 A카페" → 내쉬균형: 내가 혼자 B로 바꾸면 헛걸음 → 바꿀 이유 없음
- "둘 다 B카페" → 내쉬균형: 내가 혼자 A로 바꾸면 헛걸음 → 바꿀 이유 없음
- 이 게임엔 내쉬균형이 2개 존재한다.

흔한 오해

| 오해                   | 실제                                  |
| ---------------------- | ------------------------------------- |
| 내쉬균형 = 최선의 결과 | X, 죄수의 딜레마처럼 나쁜 균형도 존재 |
| 내쉬균형은 항상 1개    | X, 여러 개일 수 있음                  |
| 합의해서 도달하는 것   | X, 개인 유인만으로 수렴               |

비트코인 적용 — 비트코인 프로토콜 자체가 내쉬균형으로 설계되었다.

- 채굴자들이 모두 정직하게 행동하는 상태
- 혼자 규칙을 어기면 블록이 거부되어 손해
- "모두 정직" = 이탈 유인 없는 균형

---

### 3. 죄수의 딜레마 (Prisoner's Dilemma)

개인 합리성이 집단 비합리성으로 귀결되는 구조.

|          | 상대: 협력         | 상대: 배신         |
| -------- | ------------------ | ------------------ |
| 나: 협력 | (3, 3)             | (0, 5) — 나만 손해 |
| 나: 배신 | (5, 0) — 나만 이득 | (1, 1) ✓           |

- (3, 3) 둘 다 협력 → 내쉬균형 아님: 상대가 협력할 때 내가 배신하면 5를 얻음 → 이탈 유인 있음
- (1, 1) 둘 다 배신 → 내쉬균형 맞음: 상대가 배신할 때 내가 협력하면 0을 얻음 → 이탈 유인 없음

핵심 역설: 더 나은 결과 (3, 3)은 균형이 아니고, 더 나쁜 결과 (1, 1)이 균형이다.

비트코인 적용 (반전) — 비트코인은 이 딜레마를 인센티브 재설계로 해결했다.

- 배신(부정 거래) → 네트워크가 감지해 거부 + 채굴 비용 손실
- 협력(정직한 채굴) → 블록 보상 획득
- 결과적으로 배신의 보상 구조 자체가 제거된다.

|          | 상대: 정직 | 상대: 부정 |
| -------- | ---------- | ---------- |
| 나: 정직 | (3, 3) ✓   | (3, 0) ✓   |
| 나: 부정 | (0, 3)     | (0, 0)     |

정직한 채굴은 상대가 어떻게 하든 항상 보상이 3이다. "정직"이 우월 전략이 된다. 내쉬균형을 넘어서 배신할 이유 자체가 없는 구조로 재설계한 것으로, 이를 메커니즘 디자인(Mechanism Design) 이라 한다: 원하는 결과가 내쉬균형이 되도록 게임 규칙 자체를 설계하는 것.

---

### 4. 반복 게임 (Repeated Game)

1회성 게임과 무한 반복 게임에서 최적 전략이 달라진다.

- 1회성: 배신이 합리적
- 무한반복: 협력이 합리적 (팃포탯 전략 등장)

비트코인 적용 — 채굴자는 지속적으로 참여하므로 사실상 무한 반복 게임이다.

- 한 번 속여도 평판 손상 + 네트워크에서 배제 위험
- 장기적 이익(지속 보상) > 단기 이익(사기)

---

### 5. 조정 게임 (Coordination Game)

모두가 같은 선택을 해야 이득이 되는 구조.

- 모두 A 선택 → 모두 이득
- 모두 B 선택 → 모두 이득
- A/B 혼재 → 모두 손해

비트코인 적용 — 같은 프로토콜을 사용해야 거래가 가능하다.

- 포크(fork) 분쟁 = 조정 실패 사례 (BCH, BSV 등)
- 네트워크 효과가 강할수록 지배적 체인으로 수렴

---

### 사토시의 설계 철학 요약

| 문제      | 해결책                                              |
| --------- | --------------------------------------------------- |
| 배신 유혹 | 작업증명(PoW) 비용으로 배신 비용 > 배신 이익        |
| 협력 유인 | 블록 보상 + 수수료로 정직한 참여 보상               |
| 조정 문제 | 가장 긴 체인(longest chain) 규칙으로 단일 진실 수렴 |

비트코인은 인센티브를 게임이론적으로 설계해서, 참여자들이 이기적으로 행동해도 결과적으로 네트워크가 안전해지도록 만든 시스템이다.

## Part 2. 지정학적 게임이론으로 본 비트코인 수용의 필연성

### 핵심 프레임: 국가 간 게임

비트코인을 둘러싼 국가 간 관계는 다자 반복 게임이며, 플레이어는 개인이 아닌 국가(중앙은행, 정부)다.

---

### 1. 기축통화 패권 게임

현재 구조: 달러 패권의 조정 게임

- 미국은 달러 패권으로 세뇨리지(화폐 발행 이익) + SWIFT 제재권을 보유한다.
- 러시아, 이란, 중국 등 제재 대상국은 "달러 이탈" 욕구를 가진다.
- 혼자 이탈하면 제재를 받는다. 조정 문제: 같이 이탈하면 이득이지만 누가 먼저 나설 것인가.

비트코인의 역할: 조정 해결사

기존에는 달러를 대체할 공통 기준이 없어 조정에 실패했다. 비트코인은 어느 국가도 통제할 수 없는 중립 네트워크이므로 "모두 비트코인 사용"이라는 균형점으로 수렴이 가능하다.

실제 사례: 러시아-중국 에너지 거래, 이란 원유 결제에서 비트코인/암호화폐 활용 시도

---

### 2. 핵 억지력 이론과 동형(Isomorphic) 구조

핵 억지 = 상호확증파괴(MAD)

선제 핵공격 → 상대도 반격 → 둘 다 멸망 → 균형: 아무도 먼저 쏘지 않는다.

|          | 상대: 자제               | 상대: 공격               |
| -------- | ------------------------ | ------------------------ |
| 나: 자제 | (0, 0) ✓                 | (-∞, -∞) — 보복으로 공멸 |
| 나: 공격 | (-∞, -∞) — 보복으로 공멸 | (-∞, -∞)                 |

- (0, 0) 둘 다 자제 → 내쉬균형 맞음: 상대가 자제할 때 내가 공격하면 -∞ → 이탈 유인 없음
- (-∞, -∞) 공격 포함 → 내쉬균형 아님: 어느 쪽이든 자제로 바꿀 유인이 있음

핵심: 공격이 열등 전략이 되는 이유는 적이 착하기 때문이 아니라, 2차 타격 능력(second-strike capability)으로 보복이 확실하기 때문이다.

비트코인 제재 게임도 동일 구조

A국이 비트코인을 금지하면 자국 기업과 인재가 B국으로 이탈하고, B국이 암호화폐 허브로 성장하면서 A국의 경쟁력이 하락한다.

|               | 상대: 강한 규제          | 상대: 수용         |
| ------------- | ------------------------ | ------------------ |
| 나: 강한 규제 | 둘 다 손실 (상대적 균형) | 규제국만 이탈 손실 |
| 나: 수용      | 수용국 이익 독점         | 공동 성장          |

우월 전략 = 수용 (상대가 어떤 선택을 해도)

- 중국이 금지 → 홍콩/싱가포르/UAE로 자본 이동
- 미국이 규제 강화 → 유럽/두바이로 기업 이전
- 결국 규제한 나라만 손해

---

### 3. 엘살바도르 효과: 선점 게임 (First Mover Advantage)

타이밍 게임: 먼저 채택한 국가가 네트워크 효과를 독점한다.

- 초기 채택국 → IMF/World Bank 의존 탈피 + 국제 비트코인 자본 유입
- 후기 채택국 → 이미 형성된 생태계에 종속

엘살바도르 사례 (2021)

- 법정화폐 채택 → 달러 의존도 감소
- 해외 송금 수수료 10% → 거의 0%
- 관광객 유입, 비트코인 채권(화산채권) 발행 시도

이후 도미노: 중앙아프리카공화국, 아르헨티나, 짐바브웨 등 고인플레이션 국가들이 주목하기 시작했다.

---

### 4. 화폐 평가절하 경쟁 (Currency War)

A국이 돈을 찍으면 수출 경쟁력이 오르지만, B국도 돈을 찍으면 원점이 된다. 결과적으로 둘 다 인플레이션만 올라가는 죄수의 딜레마 구조다.

|              | 상대: 자제 (돈 안 찍기)         | 상대: 평가절하 (돈 찍기)       |
| ------------ | ------------------------------- | ------------------------------ |
| 나: 자제     | (3, 3) — 통화 안정, 낮은 인플레 | (0, 5) — 나만 수출 경쟁력 손실 |
| 나: 평가절하 | (5, 0) — 나만 수출 경쟁력 확보  | (1, 1) ✓ — 둘 다 인플레만 상승 |

- (3, 3) 둘 다 자제 → 내쉬균형 아님: 상대가 자제할 때 내가 평가절하하면 5를 얻음 → 이탈 유인 있음
- (1, 1) 둘 다 평가절하 → 내쉬균형 맞음: 상대가 평가절하할 때 내가 자제하면 0을 얻음 → 이탈 유인 없음

핵심 역설: 더 나은 결과 (3, 3)은 균형이 아니고, 더 나쁜 결과 (1, 1)이 균형이다. 개별 국가의 합리적 선택이 집단적으로 모두를 망하게 하는 구조다.

2020~2024 실제 상황

- 코로나 이후 전 세계 동시 양적완화
- 달러 +40%, 유로/엔/원 등도 동반 증발
- 총 공급량이 고정된 비트코인 = 화폐 전쟁의 탈출구

모든 국가가 돈을 찍는 게임에서 비트코인 보유는 어느 국가도 통제할 수 없는 자산을 확보하는 것이다. 화폐전쟁에서 중립 자산 보유가 우월 전략이 된다.

---

### 5. 미국의 딜레마: 가장 강력한 내쉬균형 압력

미국의 선택지:

- ① 비트코인 금지 → 달러 패권 유지 시도
- ② 비트코인 수용 → 달러 + BTC 이중 패권

①을 선택해도 다른 나라들이 BTC를 채택하면 달러 패권만 약해지고 BTC는 살아남는다. 금지가 우월 전략이 아닌 것이다.

2024~2025 실제 전환점

- 비트코인 현물 ETF 승인 (BlackRock, Fidelity)
- 트럼프: "전략적 비트코인 비축" 선언
- 미국이 금지에서 수용으로 전략 전환 = 게임이론적 필연

금지가 우월 전략이 아님을 미국 스스로 인정한 것이다.

---

### 전체 구조 요약

| 게임          | 귀결                             |
| ------------- | -------------------------------- |
| 기축통화 게임 | 달러 대안 필요 → 중립자산 수요   |
| 제재 게임     | 규제하면 자본 이탈 → 수용이 우월 |
| 선점 게임     | 먼저 채택한 국가가 이득          |
| 화폐 전쟁     | 인플레이션 탈출구 = BTC          |
| 미국의 전환   | 금지 불가능 → 주도권 장악 선택   |

어느 국가도 이탈 유인이 없는 내쉬균형 = 비트코인 글로벌 수용

---

### 결론

비트코인 수용이 필연인 이유는 도덕적·기술적 우월성 때문이 아니다. 국가들이 각자 이기적으로 행동한 결과가 집합적으로 비트코인 채택으로 수렴하는 게임 구조가 이미 형성되어 있기 때문이다.

사토시가 설계한 것은 단순한 화폐가 아니라, 국가 간 게임에서도 이탈 불가능한 균형점이었다.
