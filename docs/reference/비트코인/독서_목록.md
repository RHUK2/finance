## 1단계: 현재 화폐 시스템에 대한 각성

"내가 왜 가난한가"를 구조적으로 이해하는 단계

- [x] (실물책) 내가 돈을 벌고 있다는 착각: 인플레이션 환경에서 자산 가격이 올랐더라도 통화량 증가 속도보다 개인 자산 상승이 빠르지 않으면 실질적 부의 증가가 아니라는 점을 지적하며, 명목 수익과 실질 수익을 구분할 것을 촉구한다.
- [x] (전자책) 왜 그들만 부자가 되는가: 현대 통화 시스템의 구조적 결함과 자산 불평등의 원인을 파헤친다.

## 2단계: 화폐의 역사와 구조 이해

법정화폐가 어떻게 작동하고 왜 문제인지 파악

- [x] (전자책) 레이어드 머니 돈이 진화한다: 화폐의 역사를 계층적 관점에서 분석하고 비트코인의 미래 위치를 조명한다.
- [x] (전자책) 더 피아트 스탠다드(비트코인 화폐의 미래): 법정 화폐 시스템의 작동 방식과 그것이 사회 전반에 끼친 부정적 영향을 비판적으로 분석한다.
- [x] (도서관) 미래의 가격: 기술 발전으로 인한 디플레이션 압력 속에서 비트코인이 왜 필수적인지 역설한다.

## 3단계: 비트코인의 사상과 당위성

"왜 비트코인이어야 하는가"에 대한 핵심 논거

- [x] (실물책) 비트코인 스탠다드(달러는 왜 비트코인을 싫어하는가): 건전 화폐로서의 비트코인의 가치와 역사적 맥락에서의 화폐 변천사를 다룬다.
- [x] (미디어) 비트코인 낙관론: 비트코인이 어떻게 금을 대체하고 차세대 글로벌 기축 자산이 될 수 있는지 논리적으로 설명한다.
- [x] (전자책) 리얼 머니, 더 비트코인: 비트코인이 왜 인류 역사상 가장 정직하고 도덕적인 '진짜 돈'인지를 다룬다.
- [x] (미디어) 21가지 교훈: 비트코인을 통해 배운 경제, 철학, 기술에 대한 깊은 통찰을 공유한다.

- [ ] (PDF) 비트코인 핸드북: 비트코인 생태계와 기술적 기초를 체계적으로 정리한 입문서이다.

## 6단계: 돈을 대하는 철학으로 마무리

- [x] (실물책) 돈의 방정식: 돈을 버는 기술보다 어떻게 쓰고 다룰 것인가에 대한 철학을 다룬다. '부 = 가진 것 - 원하는 것'이라는 방정식으로 욕망과 자유의 관계를 탐구한다.
