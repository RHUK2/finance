## 좋은 화폐의 속성

- 희소성 (Scarcity): 공급이 한정되어 있어 마음대로 늘릴 수 없는 것 (가장 중요)
- 내구성 (Durability): 시간이 지나도 변질되거나 부식되지 않는 것
- 휴대성 (Portability): 쉽게 운반하고 보관할 수 있는 것
- 분할성 (Divisibility): 균일하고 원하는 만큼 작은 단위로 나눌 수 있는 것
- 대체 가능성 (Fungibility): 동일한 단위끼리 서로 차이가 없어 완벽히 교환 가능한 것
- 검증 가능성 (Verifiability): 누구나 쉽게 진짜인지 가짜인지 확인할 수 있는 것
- 검열 저항성 (Censorship Resistance): 어떤 중앙 기관도 거래를 차단하거나 자산을 동결할 수 없는 것. 금이나 법정화폐와 달리 비트코인이 갖는 고유한 속성으로, 개인의 재산권을 물리적·정치적 강제로부터 보호함

## 화폐의 3가지 기능

- 가치 저장 (Store of Value): 시간이 지나도 가치가 유지되는 것. 가장 근본적인 기능으로, 오늘 번 노동의 가치를 미래에 온전히 사용할 수 있어야 함
- 교환의 매개체 (Medium of Exchange): 다른 재화나 서비스로 쉽게 교환 가능한 것. 물물교환의 '욕구 이중 일치' 문제를 해결함
- 가치의 척도 (Unit of Account): 물건의 가격을 매기는 기준이 되는 것. 가치가 불안정하면 척도 기능이 무너져 경제 계산 자체가 왜곡됨

세 기능은 서로 연결되어 있다. 가치 저장 기능이 훼손되면 사람들은 그 화폐를 교환 매개로만 사용하려 하고, 척도 기능도 점차 신뢰를 잃는다.

## 화폐 vs 돈

|           | 화폐 (Currency/Fiat)              | 돈 (Money)                                 |
| --------- | --------------------------------- | ------------------------------------------ |
| 공급      | 발행 주체가 마음대로 늘릴 수 있음 | 누구도 인위적으로 늘릴 수 없음             |
| 가치 저장 | 인플레이션으로 구매력이 녹아내림  | 시간을 넘어 구매력을 보존                  |
| 예시      | 원화, 달러 등 법정화폐            | 금(자연적 희소성), 비트코인(수학적 희소성) |

화폐와 돈의 가장 결정적인 차이는 가치 저장(Store of Value) 능력에 있다.

## Money / Fiat / Currency / Cash 차이

- Money (돈): 가치 저장, 교환 매개, 가치 척도 기능을 모두 수행하며, 특히 시간을 넘어서는 구매력의 보존(희소성)이 핵심. (예: 금, 비트코인)
- Currency (통화/화폐): 유통되고 있는 교환의 매개체. 반드시 가치 저장 기능이 우수할 필요는 없으며 현재 시장에서 통용되는 결제 수단을 통칭
- Fiat (법정화폐): 정부가 법적 강제력을 부여한 화폐. 실물 자산의 담보 없이 정부에 대한 신뢰로 유지되며, 중앙집권적으로 발행량을 무한히 늘릴 수 있어 가치 저장 수단으로는 취약
- Cash (현금): 통화의 물리적 형태인 지폐와 동전. 즉각적인 결제 종결성과 익명성을 제공하지만, 물리적 분실 위험이 있고 인플레이션에 의한 구매력 하락을 방어하지 못함

## 화폐 제도 변화

| 시기      | 체제                     | 내용                                                                  |
| --------- | ------------------------ | --------------------------------------------------------------------- |
| ~1870     | 은본위제 / 복본위제      | 대부분 국가가 은 또는 금+은을 함께 사용. 영국은 1821년 금본위제 선도  |
| 1870~1914 | 금본위제                 | 화폐 가치를 금으로 직접 뒷받침. 통화가 금으로 자유롭게 교환 가능      |
| 1918~1939 | 금환본위제               | 주요 통화(달러, 파운드)가 금에 고정되고, 다른 나라 통화가 그것에 연동 |
| 1944~1971 | 브레턴우즈 체제          | 미국 달러를 기축통화로 삼고 달러를 금에 고정 (금 1온스 = 35달러)      |
| 1971      | 금 태환 중지 (닉슨 쇼크) | 베트남전 비용으로 달러 과다 발행 → 금 태환 중단. 실물 담보 소멸       |
| 1973      | 변동 환율제              | 외환 시장 수요·공급에 따라 환율이 자유롭게 변동                       |
| 1974      | 페트로달러 체제          | 사우디와 협정. 석유 거래를 달러로만 결제 → 달러가 석유를 담보로 삼음  |
| 2008      | 리먼 브라더스 사태       | 과도한 레버리지로 인한 글로벌 금융위기. 비트코인 탄생의 직접적 계기   |
| 2009      | 비트코인 탄생            | 사토시 나카모토, P2P 전자 현금 시스템 구동 시작                       |

1971년은 인류 역사상 처음으로 실물 담보 없는 화폐 시대가 열린 해다. 5000년 화폐 역사에서 이 50년은 극히 짧은 실험이다.

### 금환본위제에서 달러·파운드가 기준이 된 이유

기준 통화가 되려면 "이 나라 돈은 믿을 수 있다"는 신뢰가 필요하며, 그 근거는 금 보유량 + 경제력 + 채권국 지위였다.

- 달러: 1차 대전 당시 연합국에 물자·자금 공급 → 전후 세계 최대 채권국. 전쟁 중에도 금 보유량을 유지했으며 1920년대에 전 세계 금의 약 40% 보유
- 파운드: 19세기 내내 세계 최대 무역국이자 금융 허브(런던). 금본위제를 가장 먼저(1821년) 도입하여 신뢰도 선점. 대영제국 식민지 네트워크가 파운드 사용을 강제
- 다른 나라들의 금 부족: 전쟁으로 독일·프랑스·러시아 등은 금을 소진하고 통화 신뢰 붕괴. 모든 나라가 금을 직접 보유하기엔 금이 부족하여 신뢰할 수 있는 통화를 준비금으로 쓰는 절충안이 금환본위제

2차 대전 후에는 파운드마저 흔들리며 달러만 남아 브레턴우즈 체제로 이어진다.

### 브레턴우즈에서 파운드가 밀려난 이유

- 전쟁 비용 고갈: 영국은 1939~1945년 전쟁 중 금과 외환 보유고를 거의 소진. 미국에서 무기·물자를 구매하느라 막대한 달러 부채를 짊어짐
- 채권국 → 채무국 전환: 19세기 세계 최대 채권국이었으나 두 번의 세계대전을 거치며 미국의 최대 채무국으로 역전
- 협상력의 차이: 브레턴우즈 협상(1944년) 당시 미국은 전 세계 금의 약 70% 보유, 영국은 거의 없음. 케인스(영국)가 초국가 화폐 "방코르(Bancor)"를 제안했으나 미국에 거부당하고 화이트(미국)의 달러 기축안이 채택
- 대영제국 해체: 전후 식민지 독립이 가속화되며 파운드 사용을 강제하던 네트워크 붕괴. 1947년 인도 독립을 시작으로 아프리카·아시아 식민지 연쇄 독립

파운드는 신뢰의 물적 기반(금, 채권국 지위, 제국 네트워크)을 모두 잃었고, 달러는 반대로 그것을 모두 갖게 된 구조적 역전이었다.

### 닉슨 쇼크에 반발이 없었던 이유

- 국민은 이미 금과 단절: 1933년 루즈벨트의 금 소유 금지령(행정명령 6102) 이후 미국인은 금을 직접 보유하지 못했음. 닉슨 쇼크는 외국 정부의 달러→금 교환권을 없앤 것이라 일반 시민이 체감하지 못함
- 추상적인 조치: 물가 상승이나 실업처럼 즉각적으로 느껴지지 않음. 지갑 속 달러는 여전히 작동했기 때문
- 전쟁 프레임으로 포장: "투기꾼들의 달러 공격으로부터 미국을 보호"라고 발표. 베트남전 반전 여론에 묻힘
- 단기 경기 부양: 금 태환 중지 직후 경기 부양 효과가 나타났고 닉슨은 1972년 대선에서 압승. 피해는 1973년 오일쇼크와 1970년대 스태그플레이션으로 나중에 나타남
- 반발은 외국 정부: 실제 불만 세력은 프랑스(드골) 등 외국 정부였으나, 냉전 구도에서 미국에 맞서기 어려웠고 1974년 페트로달러 체제로 봉합됨

인플레이션 세금은 가장 조용한 세금이다. 피해가 즉각적이지 않고 분산되어 서서히 나타나는 구조였기 때문에 반발이 일어나지 않았다.

## 이자 시스템의 구조적 모순

### 이자는 화폐 팽창 없이도 가능한가?

개인 간 이자는 화폐 팽창 없이 가능하다. A가 B에게 100만원을 빌려주고 110만원을 돌려받는다면, 이자 10만원은 B가 노동·사업으로 번 돈이 A에게 이전된 것이다. 화폐 총량은 불변이다.

문제는 은행이 중개할 때 발생한다. 현대 은행은 예금의 일부만 남기고 나머지로 대출하는 부분 지급준비율 구조로 운영되기 때문에 대출 시 없던 돈을 창조한다. 이렇게 되면 경제 전체의 총 부채가 총 화폐량을 초과하게 된다.

- 예: 은행이 100원을 대출하고 110원(원금+이자)을 요구하면, 경제 전체 상환 의무는 110원이지만 실제 유통되는 돈은 100원뿐. 10원은 어딘가에서 새로 만들어지거나 누군가가 디폴트를 내야 한다
- 해결 방법: 신규 화폐 발행 / 디폴트 / 이자 수취자의 재순환
- 현대 신용화폐 시스템은 총 부채가 계속 증가해야 유지됨. 성장이 멈추면 시스템 자체가 붕괴 압력을 받는 이유가 여기에 있다

중개자 자체가 문제가 아니라 부분 지급준비율 구조가 문제다. 100% 지급준비율로 운영하면 은행이 중개해도 화폐 팽창은 발생하지 않는다.

### 이익 사유화 + 손실 공유화 = 구조적 모순

| 구조          | 설명                                  |
| ------------- | ------------------------------------- |
| 일관된 구조 A | 이익 사유 + 손실 사유 (완전 자본주의) |
| 일관된 구조 B | 이익 공유 + 손실 공유 (완전 사회주의) |
| 현재          | 이익 사유 + 손실 공유 (최악의 혼합)   |

현재 시스템은 힘 있는 쪽이 유리한 방향으로만 규칙을 바꿔온 결과물이다.

### 돈 관리 기관의 문제

- 돈을 관리하는 기관이 그 돈으로 사유화된 이익을 추구하는 것 자체가 근본 문제
- 예금(남의 돈)으로 투자/대출 → 이익 사유화
- 실패하면 예금자/납세자 부담
- 화폐 발행권으로 인플레이션을 통해 암묵적 세금 수취

## 역사적으로 번영한 시대의 화폐 시스템

| 시대                      | 화폐 구조               | 결과                         |
| ------------------------- | ----------------------- | ---------------------------- |
| 로마 공화정 전성기        | 은 함량 고정 데나리우스 | 장기 번영                    |
| 로마 후기                 | 은 함량 축소 시작       | 초인플레이션 → 제국 붕괴     |
| 금본위제 시대 (1870~1914) | 공급 고정               | 역사상 가장 긴 평화적 성장기 |
| 미국 19세기               | 금/은 본위              | 세계 최대 경제로 성장        |
| 바이마르 독일             | 무제한 화폐 발행        | 초인플레이션 → 나치 등장     |
| 1971년 이후               | 완전 불태환             | 부채/GDP 역사적 최고치       |

번영의 끝은 거의 예외 없이 화폐 조작의 시작과 일치한다.

## 공급 고정 = 올바른 가격 신호

현재 시스템의 결함:

- 중앙은행이 금리와 공급을 조절 = 경제 전체 가격 신호를 한 기관의 판단으로 덮어씀
- 금리는 돈의 가격 — 시장이 아닌 회의실에서 결정되면 모든 투자 판단이 왜곡됨
- 인간이 개입하면 공급은 필연적으로 늘어날 수밖에 없는 구조

비트코인의 논리:

- 공급이 고정되면 가격은 순수하게 수요만을 반영한다
- 수요가 증가하면 가격이 오른다 — "자원을 더 투입하라"는 시장의 신호
- 수요가 감소하면 가격이 내린다 — "과잉투자를 경고"하는 시장의 신호

인위적인 금리 조작은 이 신호 자체를 오염시킨다. 낮은 금리가 유지되면 수익성 없는 사업에도 자본이 흘러들고(과잉투자), 금리가 오르는 순간 부실이 한꺼번에 드러나는 붐-버스트 사이클이 반복된다.

디플레이션 반박:

- 기술 발전으로 인한 가격 하락(PC, 스마트폰)은 소비를 막지 않았음
- 인플레이션이 오히려 "지금 안 쓰면 손해"라는 인위적 소비 압박을 만듦
- 디플레이션이 위험한 건 화폐 자체가 아니라 고정된 부채 구조 때문
  - 부채는 명목 금액으로 고정된다. 집값 1억일 때 1억을 빌렸는데 디플레이션으로 집값이 5천만원이 되어도 갚아야 할 빚은 여전히 1억이다
  - 디플레이션 환경에서는 돈의 가치가 오르므로 실질 부채 부담이 더 무거워진다. 빚 있는 사람일수록 쪼들리고 → 소비 감소 → 경기 침체 → 자산 가치 추가 하락의 악순환
  - 반대로 부채 없이 저축한 사람에게 디플레이션은 이득이다. 디플레이션 자체가 문제가 아니라, 현대 경제가 부채 위에 세워져 있다는 구조가 문제다
