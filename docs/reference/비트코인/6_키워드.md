## 기본 프로토콜

### UTXO (Unspent Transaction Output)

아직 사용되지 않은 트랜잭션 출력값으로, 비트코인의 잔고 관리 방식. 계좌 잔액이 아닌 개별 동전처럼 각각의 미사용 출력값을 추적하여 소유권을 증명함

### 반감기 (Halving)

210,000블록(약 4년)마다 비트코인 채굴 보상이 절반으로 줄어드는 메커니즘. 공급량을 조절하여 희소성을 유지함

### 난이도 조정 (Difficulty Adjustment)

2,016블록(약 2주)마다 채굴 난이도를 자동으로 재조정하여 블록 생성 시간을 평균 10분으로 유지하는 메커니즘

### 멤풀 (Mempool)

아직 블록에 포함되지 않은 미확인 트랜잭션들이 대기하는 메모리 공간. 채굴자는 수수료가 높은 트랜잭션을 우선 선택하여 블록에 포함시킴

### 노드 (Node)

비트코인 블록체인의 전체 사본을 보유하고 네트워크의 규칙을 독립적으로 검증하는 컴퓨터. 풀 노드를 운영함으로써 제3자에 의존하지 않고 트랜잭션의 유효성을 직접 확인할 수 있음

### Coinbase 트랜잭션

각 블록의 첫 번째 트랜잭션으로, 채굴자가 블록 보상(새로 발행된 비트코인)과 해당 블록의 모든 수수료를 받는 특수 트랜잭션. 입력값(Input)이 없으며 반감기마다 보상이 절반으로 줄어듦. (거래소 Coinbase와는 무관)

### BIP (Bitcoin Improvement Proposal)

비트코인 프로토콜 개선 사항을 공식적으로 제안하고 논의하는 표준 절차 문서. 누구나 제안할 수 있으며 커뮤니티 검토를 거쳐 채택됨. BIP39(시드 구문), BIP44(HD 지갑 경로), BIP141(SegWit) 등

### OP_RETURN

해당 출력값을 소비 불가능한 것으로 표시하고 최대 80바이트의 임의 데이터를 블록체인에 기록할 수 있게 함. UTXO 집합을 오염시키지 않으면서 타임스탬프, 인증서 등을 체인에 영구 기록하는 데 사용

## 트랜잭션

### PSBT (Partially Signed Bitcoin Transactions)

부분적으로 서명된 비트코인 트랜잭션 형식. 오프라인 서명이나 다중 서명 환경에서 여러 당사자가 단계적으로 트랜잭션에 서명할 수 있도록 하는 표준화된 프로토콜

### RBF (Replace-By-Fee)

아직 블록에 포함되지 않은 미확인 트랜잭션의 수수료를 더 높게 설정하여 새로운 트랜잭션으로 대체할 수 있는 메커니즘

### CPFP (Child Pays For Parent)

미확인 트랜잭션의 출력값을 사용하는 자식 트랜잭션에 높은 수수료를 부여하여, 채굴자가 부모 트랜잭션과 자식 트랜잭션을 함께 처리하도록 유도하는 수수료 가속 기법

## 채굴

### 해시레이트 (Hashrate)

비트코인 네트워크에서 채굴자들이 연산 작업을 수행하는 총 연산 능력의 단위. 높을수록 네트워크의 보안성이 강화됨

### 작업 증명 (Proof of Work, PoW)

채굴자가 막대한 연산(전기 에너지)을 소비하여 특정 조건을 만족하는 해시값을 찾아야만 블록을 생성할 수 있도록 하는 합의 메커니즘. 이 '일(Work)'의 물리적 비용이 블록체인의 변조를 경제적으로 불가능하게 만드는 핵심 보안 장치

### ASICs (Application-Specific Integrated Circuit)

비트코인의 SHA-256 해시 알고리즘만을 수행하도록 특화 설계된 반도체 칩. 범용 CPU·GPU 대비 수천 배 이상의 에너지 효율을 가지며, 현재 비트코인 채굴은 사실상 ASIC 없이는 불가능함

### 채굴 풀 (Mining Pool)

개별 채굴자들이 해시파워를 모아 함께 블록을 탐색하고, 발견 시 기여도에 비례하여 보상을 나누는 집합적 채굴 방식. Foundry USA, AntPool, F2Pool 등이 주요 풀임

### 스트라텀 프로토콜 (Stratum Protocol)

채굴 풀과 개별 채굴 장비(ASIC) 사이의 통신을 위한 표준 네트워크 프로토콜

### 머클 트리 (Merkle Tree)

블록에 포함된 모든 트랜잭션을 효율적으로 요약하는 이진 해시 트리 구조. 최종적으로 하나의 머클 루트(Merkle Root)를 도출하여 블록 헤더에 포함시킴. 전체 블록을 다운로드하지 않고도 특정 트랜잭션의 포함 여부를 증명할 수 있는 SPV(간이 지급 검증)의 기반

## 레이어 2 및 업그레이드

### SegWit (Segregated Witness, 분리된 증인)

2017년 활성화된 소프트포크 업그레이드. 서명(증인) 데이터를 본문과 분리하여 블록의 실질적 용량을 늘리고 트랜잭션 가변성(Malleability) 문제를 해결함. 라이트닝 네트워크 구현의 전제 조건

### Taproot / Schnorr 서명

2021년 활성화된 비트코인의 주요 업그레이드. Schnorr 서명은 여러 서명을 하나로 집계하여 다중 서명 트랜잭션의 크기와 수수료를 줄이고, Taproot는 복잡한 스크립트 조건을 단순한 단일 서명처럼 보이게 만들어 프라이버시와 효율성을 동시에 개선함

### 다중 서명 (Multisig)

m-of-n 구조로, n개의 키 중 m개의 서명이 있어야만 비트코인을 사용할 수 있는 잠금 방식. 단일 키 분실이나 도난 리스크를 분산하여 보안을 강화하며, 기관 수탁과 콜드 스토리지 설계에 활용됨

### 라이트닝 네트워크 (Lightning Network)

비트코인의 2계층(Layer 2) 결제 프로토콜. 두 참여자가 멀티시그 채널을 개설하면 온체인 거래 없이 즉각적이고 저렴한 소액 결제를 주고받을 수 있음. 채널 개설과 최종 정산 시에만 온체인 트랜잭션이 필요함
