## 현물거래 (Spot Trading)

- 즉시 소유: 거래 즉시 실제 자산(BTC 등)을 소유
- 레버리지 없음: 보유한 자금만큼만 거래 가능
- 손실 한도: 투자 원금까지만 손실 발생
- 보관 필요: 구매한 자산을 직접 보관/관리

## 선물거래 (Futures Trading)

- 미래 계약: 특정 가격으로 미래에 사고팔기로 하는 계약
- 레버리지 가능: 증거금(margin)으로 원금보다 큰 포지션 진입 (예: 10x = 원금의 10배)
- 롱/숏 모두 가능: 가격 하락에도 수익 가능 (숏 포지션)
- 청산 위험: 증거금 소진 시 강제 청산(liquidation)
- 만기 존재: 영구 선물(perpetual)은 만기 없지만 펀딩비 발생

## 핵심 차이 비교

| 항목      | 현물        | 선물                |
| --------- | ----------- | ------------------- |
| 자산 소유 | O           | X (계약만 보유)     |
| 레버리지  | X           | O                   |
| 숏 포지션 | 어려움      | 쉬움                |
| 리스크    | 제한적      | 원금 초과 손실 가능 |
| 비용      | 거래 수수료 | 수수료 + 펀딩비     |

## 선물거래의 기원

선물거래는 농산물 시장에서 시작됨 (19세기 미국 시카고).

- 농부: 봄에 씨를 뿌리지만 가을 수확 때 가격이 폭락하면 생산 비용도 못 건질 수 있음
- 곡물 구매자: 가을에 가격이 폭등하면 원가 부담이 커짐

둘 다 가격 불확실성을 없애고 싶어서, 봄에 미리 "가을에 이 가격에 팔고 사겠다"고 계약하는 시장이 생김.

## 세 가지 참여자

| 참여자                   | 목적                                        |
| ------------------------ | ------------------------------------------- |
| 헤저 (Hedger)            | 실제 자산 보유자, 가격 위험 제거 목적       |
| 투기자 (Speculator)      | 가격 변동으로 수익 추구, 시장에 유동성 공급 |
| 차익거래자 (Arbitrageur) | 현물-선물 가격 차이 이용                    |

### 왜 투기자가 필요한가

현실에서 헤저끼리 항상 딱 맞게 만나기 어려움. 투기자가 끼어들면서 시장에 항상 거래 상대방이 존재하게 됨.

- 헤저: 위험을 없애려고 참여
- 투기자: 위험을 가져가서 수익 추구 → 시장의 유동성 공급

## 원유 선물 시장 예시

### 등장인물

- 산유국/석유회사 (헤저): 원유를 캐서 팜
- 정유회사 (헤저): 원유를 사서 휘발유로 만들어 팜
- 투기자: 가격 변동으로 수익 추구

### 시나리오

현재 원유 현물 가격: 배럴당 $80

산유국

- 3개월 후 100만 배럴 팔 예정
- 가격 하락 대비 → 선물 시장에서 $78에 숏 포지션 진입

정유회사

- 3개월 후 원유 100만 배럴 필요
- 가격 상승 대비 → 선물 시장에서 $78에 롱 포지션 진입

투기자

- "중동 긴장으로 공급 줄 것 같으니 가격 오를 것"
- $78 롱 포지션 진입

### 3개월 후 실제 가격이 $60이 됐다면

|          | 현물                     | 선물         | 최종               |
| -------- | ------------------------ | ------------ | ------------------ |
| 산유국   | $60에 팜 (예상보다 손해) | 숏 수익 +$18 | 실질 $78에 판 효과 |
| 정유회사 | $60에 삼 (예상보다 이득) | 롱 손실 -$18 | 실질 $78에 산 효과 |
| 투기자   | 없음                     | 롱 손실 -$18 | 손해               |

→ 헤저는 가격이 어떻게 되든 $78 수준에서 거래한 효과를 얻음

## 헤징의 실제 구조

헤저는 현물 거래와 선물 거래를 동시에 진행함.

산유국 예시

지금

- 현물: 계속 원유 생산 중
- 선물: 숏 포지션 진입 → 미래 판매 가격 고정

3개월 후

- 현물: 시장에서 실제로 원유 팜 ($60에)
- 선물: 숏 포지션 청산 (수익 +$18 챙김)

합산하면 $78에 판 효과

### 비율 조절

100% 헤징이 꼭 정답은 아니라서 상황에 따라 조절함.

- 가격 오를 것 같으면: 일부만 숏 → 나머지는 가격 상승 수혜
- 가격 내릴 것 같으면: 전량 숏 → 하락 리스크 완전 차단

### 정유회사의 복잡한 헤징

정유회사는 원유를 사는 동시에 휘발유를 파는 구조라서 두 가지를 동시에 헤징함.

- 원유 선물 롱 (원자재 구매 헤지)
- 휘발유 선물 숏 (완제품 판매 헤지)

이 두 가격의 차이를 크랙 스프레드(crack spread) 라고 하며, 이것 자체를 거래하기도 함.

## 선물 시장의 현실과 문제점

현실의 선물 시장은 투기자가 압도적으로 많고 실제 헤저는 소수.

### 투기자가 많아도 괜찮은 이유

투기자들끼리의 거래가 가격 발견 기능을 해줌.

- 시장의 미래 가격 기대가 가격에 반영됨
- 헤저는 그 가격을 기준으로 계약하면 됨

### 투기자가 지나치게 많을 때 문제

- 가격 왜곡: 실제 수요/공급과 무관한 방향으로 가격이 움직임
- 변동성 증폭: 레버리지 청산이 연쇄적으로 터지면서 폭락/폭등
- 꼬리가 몸통을 흔드는 현상: 선물 시장이 현물 시장 가격을 끌고 다님

대표 사례: 2008년 원유 $147 폭등. 투기자들이 "전쟁 날 것 같다"며 선물을 대거 매수 → 선물 가격 급등 → 차익거래자들이 현물도 매수 → 실제 수요 변화 없이 현물 가격도 급등.

### 현물 가격과 선물 가격의 수렴

선물 가격과 현물 가격은 서로 연동되어 있음.

- 선물 가격이 현물보다 너무 높으면 → 차익거래자가 현물 사고 선물 팔아서 수렴
- 선물 가격이 현물보다 너무 낮으면 → 반대로 작동

만기가 가까워질수록 선물 가격은 현물 가격에 수렴함.
