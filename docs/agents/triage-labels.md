# Triage 라벨

스킬들은 다섯 개의 표준 triage 역할로 말한다. 이 파일은 그 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 매핑한다.

| mattpocock/skills 라벨 | 이 저장소 라벨    | 의미                                 |
| ---------------------- | ----------------- | ------------------------------------ |
| `needs-triage`         | `needs-triage`    | 메인테이너의 판단이 필요한 이슈      |
| `needs-info`           | `needs-info`      | 제보자의 추가 정보를 기다리는 중     |
| `ready-for-agent`      | `ready-for-agent` | 명세가 끝나 AFK 에이전트가 착수 가능 |
| `ready-for-human`      | `ready-for-human` | 사람이 직접 구현해야 함              |
| `wontfix`              | `wontfix`         | 처리하지 않음                        |

스킬이 역할을 언급하면(예: "AFK 준비 완료 triage 라벨을 붙인다") 이 표의 해당 라벨 문자열을 쓴다.

로컬 마크다운 트래커에서는 이 라벨 문자열을 이슈 파일 상단의 `Status:` 줄 값으로 기록한다.

다른 용어 체계를 쓰게 되면 오른쪽 열만 고치면 된다.
