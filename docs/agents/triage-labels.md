# Triage 라벨

스킬들은 다섯 가지 분류 역할로 말한다. 이 저장소의 이슈 트래커(`.scratch/` 이슈 파일 맨 위 `Status:` 줄)는 그 이름을 그대로 쓴다.

| 스킬이 말하는 역할 | 이 저장소의 라벨  | 뜻                               |
| ------------------ | ----------------- | -------------------------------- |
| `needs-triage`     | `needs-triage`    | 아직 분류하지 않은 것            |
| `needs-info`       | `needs-info`      | 보고자에게 물어볼 것이 남은 것   |
| `ready-for-agent`  | `ready-for-agent` | 명세가 충분해 에이전트가 맡을 것 |
| `ready-for-human`  | `ready-for-human` | 사람이 직접 구현해야 하는 것     |
| `wontfix`          | `wontfix`         | 하지 않기로 한 것                |

스킬이 역할 이름을 말하면("AFK 준비 라벨을 붙여라") 오른쪽 열의 문자열을 쓴다. 라벨을 늘리거나 이름을 바꾸려면 이 표를 먼저 고친다.
